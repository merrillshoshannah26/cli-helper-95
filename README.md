# cli-helper-95

cli-helper-95 is a powerful command-line tool designed to streamline your daily tasks and enhance productivity. Built with Python, this utility provides a set of efficient features to manage files, automate scripts, and facilitate quick access to important resources.

## Features

- **File Management**: Effortlessly organize, rename, and delete files with user-friendly commands to keep your directories tidy.
- **Script Automation**: Create and run custom scripts directly from the command line, reducing mundane tasks to a single command.
- **Resource Quick Access**: Set up shortcuts for frequently used commands and scripts to save time and streamline your workflow.
- **User-Friendly Interface**: Intuitive command structure that minimizes the learning curve and enhances usability for beginners and experienced users alike.

## Installation

To install cli-helper-95, make sure you have Python 3.6 or higher installed, then run the following command:

```bash
pip install cli-helper-95
```

## Basic Usage Example

Once installed, you can start using cli-helper-95 by executing commands directly in your terminal. Here’s a quick example to rename a file:

```bash
cli-helper rename old_file.txt new_file.txt
```

Additionally, to run a custom script stored in your directory, use:

```bash
cli-helper run my_script.py
```

For more commands and detailed usage instructions, consult the help menu:

```bash
cli-helper --help
```
